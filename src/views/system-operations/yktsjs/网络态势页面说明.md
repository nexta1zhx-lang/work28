# 网络态势监控页面说明

## 一、页面概述

- **文件**：`src/views/system-operations/yktsjs/NetworkSituation.vue`
- **路由**：`/network-situation`
- **定位**：以"网络拓扑图"的形式展示网络 → 成员 → 链路 的连接关系，实时监控网络状态、成员信息、链路质量与信息流量。
- **技术栈**：Vue 2.6 + Element UI + `@antv/x6`（画布）+ `@antv/layout`（圆形图布局）

## 二、页面布局

```
┌──────────────────────────────────────────────────────────┐
│  顶部：标题 + 网络号选择器 + 图例(在网/离线) + 刷新时间         │
```

## 三、数据来源（后端接口）

| 接口                | 方法 | 用途                                               |
| ------------------- | ---- | -------------------------------------------------- |
| `/rest/wlzt/page`   | POST | 查询网络列表（网络号+参数），pageSize=999 一次拉全 |
| `/rest/wlzt/{wlh}`  | GET  | 查询指定网络的**拓扑数据**（成员+链路+邻接）       |
| `/rest/xxlltj/page` | POST | 信息流量统计（发送/接收条数）                      |
| `/rest/xxfsjg/page` | POST | 消息发送结果（源/目的平台、成功/失败、时间）       |

## 四、拓扑数据结构（图结构）

后端 `/rest/wlzt/{wlh}` 返回**嵌套的图数据**（非树）：

```
Net      WLH 网络号 | WLMC 网络名称 | WLLX 网络类型 | WLCYS 成员数量
  └─ WLCYLB[] 成员列表（节点）
       PTID 成员ID(=PTBSH) | PTMC 名称 | PTWLDZ 网络地址 | PTLLS 链路数
       └─ PTLLLB[] 链路列表
            LLH 链路号 | LLLX 链路类型 | LLLXMC 类型名 | LLJKZT 健康状态
            └─ LJJDLB[] 邻接节点列表（边的引用）
                 LJJDID 邻接成员ID | LJJDZT 状态(0在网/1离线) | LJJDMC 邻接名称
```

**图关系**：成员 = 节点；链路的 `LJJDLB[].LJJDID` 指向同网络其它成员的 `PTID` → 构成边。

## 五、前端渲染逻辑

### 1. 拓扑画布（X6 + 圆形布局）

- 每个成员（`WLCYLB`）生成一个 X6 节点，id = `pt{PTID}`
- 遍历成员链路的 `LJJDLB`，用 `LJJDID` 在 `ptMap` 中匹配同网络其它成员 → 生成连线
- 连线按**无序节点对去重**（两端都记录时只画一条）
- 使用 `@antv/layout` 的 **CircularLayout 圆形布局**：成员围成圆、链路作为弦（半径随成员数自适应）
- `zoomToFit` 自适应缩放

### 2. 图元样式（无外框，上下排列）

```
      ⦿        ← 计算机图标（圆形底衬托）
   成员名称      ← PTMC（超长截断为12字符+…）
     IP地址      ← PTWLDZ（等宽字体）
```

- 节点无矩形外框，选中/悬浮高亮
- 悬浮显示完整平台名称 tooltip
- 点击节点 → 弹出成员详情浮层（平台ID、链路数、链路及邻接状态）

### 3. 连线样式

- **在网**（`LJJDZT=0`）：绿色实线
- **离线**（`LJJDZT=1`）：红色虚线
- 连线中间有**圆形徽章**显示链路号（`LLH`），颜色随状态

### 4. 网络参数面板（右上角）

选择网络后显示：网络号、网络类型（13种枚举中文）、频段（自动 MHz/GHz 换算）、带宽、剩余带宽、丢包率（%）、健康状态。数值带状态色（健康绿/警告黄/危险红）。

### 5. 左侧信息面板（3 个 tab）

| tab      | 数据源                      | 显示                                                            |
| -------- | --------------------------- | --------------------------------------------------------------- |
| 消息发送 | `/rest/xxfsjg/page`（50条） | 源/目的平台、消息类型、成功/失败、发送/接收时间（年月日时分秒） |
| 信息转发 | 前端模拟数据                | 源→目的、信息名、转发状态（成功/失败/转发中）、转发条数、时间   |
| 信息流量 | `/rest/xxlltj/page`         | 信息名、链路类型、源/目的平台、发送/接收条数、时间              |

## 六、交互与数据加载

- **页面加载**：查询网络列表 + 默认网络拓扑 + 信息流量 + 消息发送（一次，**不轮询**）
- **切换网络**：直接查询该网络拓扑（重建画布）+ 刷新该网络信息流量
- **无轮询、无合并/去重**：逻辑简单，选择网络即查该网络

## 七、关键实现要点（踩坑记录）

1. **X6 text 定位**：自定义 markup 的 `text` 元素会被 X6 自动加 `translate(节点中心)` 变换，`x/y` 是**相对中心偏移**；文字定位必须用 `refX/refY` + `textAnchor/textVerticalAnchor`
2. **X6 必须 `async: false`**，否则节点不挂载到 DOM
3. **连线去重**：同一条链路两端都会记录，需按"无序节点对"去重，否则画双向重叠线
4. **圆形布局**：`@antv/layout` 的 `CircularLayout`，`radius = max(180, 成员数×75)` 自适应
5. **状态映射**：`LJJDZT`（1入网→在网0 / 其余→离线1）需在后端统一映射，避免语义颠倒

## 八、数据说明

- 数据库表：`WLLLZT`（网络链路状态）、`WLZT`（网络状态）、`XXLLTJ`（信息流量）、`XXFSJG`（消息发送结果）、`PTXX`（平台）
- 成员 `PTID` 使用平台编识号 `PTBSH`，邻接 `LJJDID` 也是 `PTBSH`，同一套编号
- 拓扑示例网络：201(星型)、202(链式)、203(环型)、204(网状)、205(双节点)、56789、2
